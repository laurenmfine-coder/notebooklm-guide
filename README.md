A comprehensive guide for medical students to master Gemini Notebook and optimize study strategies based on learning style, training stage, and available time.

## 🚀 Deployment Instructions

### GitHub Pages (Current Setup)

1. **Upload Files**
   - Go to your repository: `https://github.com/laurenmfine-coder/notebooklm-guide`
   - All site files should be in the `docs` folder
   - Commit changes

2. **GitHub Pages Settings**
   - Go to Settings → Pages
   - Source: Deploy from a branch
   - Branch: `main`
   - Folder: `/docs`
   - Click Save

3. **Access Your Site**
   - Wait 1-2 minutes for deployment
   - Visit: `https://laurenmfine-coder.github.io/notebooklm-guide/`
